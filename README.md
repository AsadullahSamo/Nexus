# Nexus — Investor & Entrepreneur Collaboration Platform

Nexus is a full-stack web platform that bridges the gap between entrepreneurs and investors. It enables deal flow management, secure document sharing, meeting scheduling, real-time communication, and video collaboration — all in one place.

## Getting Started

### Client
```bash
cd client
npm install
npm run dev
```

### Server
```bash
cd server
npm install
cp .env.example .env   # fill in your values
npm run dev
```
